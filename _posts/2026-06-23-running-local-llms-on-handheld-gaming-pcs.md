# Running Local LLMs on Handheld Gaming PCs

Recent advances in AI hardware make it possible to run local large language models on portable devices.

## Test Environment

Hardware:

* Intel Core Ultra platform
* 32GB RAM
* NVMe SSD

Software:

* Ollama
* Open WebUI
* Docker

## Models Tested

### Llama 3 8B

Performance:

* Good response quality
* Suitable for coding assistance
* Moderate memory requirements

### Qwen 3 8B

Performance:

* Strong multilingual support
* Excellent reasoning capability

## Resource Usage

Typical requirements:

| Model | RAM      |
| ----- | -------- |
| 7B    | 8-12 GB  |
| 8B    | 12-16 GB |
| 14B   | 20-24 GB |

## Use Cases

* Offline AI assistant
* Infrastructure troubleshooting
* Kubernetes documentation search
* Code generation

## Final Thoughts

Local AI is becoming practical for engineers who require privacy, portability, and low-latency inference.
